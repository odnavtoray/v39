# 1/2 — Одна Друга — Real v2

Что изменено:
- утвержденный светлый круглый логотип;
- более полноценный ПК/мобильный дизайн;
- только категория «Взуття»;
- создание объявления с живым просмотром до 5 фотографий;
- клик по фото делает его большим и главным;
- поворот фото ↺/↻ и удаление до публикации;
- выбранное главное фото отправляется первым;
- полноценная галерея объявления: клик по миниатюре открывает фото крупно;
- кнопка «Редагувати оголошення» для владельца;
- редактирование текста, параметров и существующих фото;
- «Шукаю конкретне» теперь показывает человеческие карточки совпадений, а не JSON/коды;
- избранное, чат, телефон, поделиться, жалоба, рейтинг доверия;
- мобильная сетка 1/2 колонки и 3 колонки в горизонтальном режиме.

Запуск:
1) распаковать папку;
2) открыть терминал в папке;
3) `py -m pip install -r requirements.txt`
4) `py app.py`
5) открыть `http://127.0.0.1:5000`

Тестовый код регистрации: 1111

Для публичного запуска еще нужны: реальный SMS OTP, PostgreSQL, облачное хранение фото, HTTPS, резервные копии, юридические страницы, production-сервер и реальная система уведомлений.
